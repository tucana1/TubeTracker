Round 2: rules for the one held-out look per frozen candidate. Written 2026-09-25 ~22:45 UTC, before any round-2 held-out look.

Held-out synthetic movies: v5 seeds 7, 8, 13, 14, 15 (never trained, tuned or calibrated on). One look per frozen candidate.
The candidate is frozen first: its model file sha1 and every option are recorded in SCR/heldout_round2/<cand>/frozen.json.

Metric: sparsetrack.evaluate.score(truth, pred, onset_tol=50): length_full within max(2 px, 10%), and onset hits.
There are two truth documents: the original truth, and the human-style document (redteam rescore.docs_for "human_t2").
Pairing: paired bootstrap over grains (prototypes/learned_evidence/evaluate.py paired_bootstrap), candidate minus baseline.

A. Evidence-model candidates (e.g. simreal v4). Baseline: the shipped v2 under the SAME decoder, the current per-bin defaults.
   This is mainly a real-footage fix, so the held-out look is a NON-INFERIORITY check on thin synthetic tubes.
   Adopt as the default model only if ALL of these hold:
     1. Held-out length_full point difference >= -1.0 percentage point, and its 95% lower bound >= -3.0 points,
        on the original truth.
     2. Held-out onset hits: point difference >= -1.0 point.
     3. The real-footage audit check, judged BEFORE the held-out look, shows more gross fixes than gross breaks.
        A gross fix is a tubeless call or a missed thick tube that now matches the audit estimate (±25%).
        A gross break is a new tubeless call, a new foreign-tube reading, or an onset now more than 6 bins off.
   Otherwise, ship it as an option only, off by default, with the numbers stated.

B. Label-free per-movie adaptation (e.g. selftrain). The same rules as A, on the same held-out movies. The adaptation
   runs on each held-out movie's own frames, which is allowed because no labels are used. The baseline is the
   unadapted model under the same decoder.

C. New decoders or paradigms (birthmap, invrender). Baseline: the per-bin decoder at its current defaults on v2.
   Adopt as a default only if the held-out length_full improves (95% lower bound > 0) AND the real-footage audit
   check is no worse. Otherwise it stays a development-test run.

Any rule failing means no adoption, with no second look. A fix after a failed look makes a new frozen version,
scored once on the same held-out movies, and the report states that it is the second version scored there.

   Otherwise it ships as an option, off by default, with the numbers stated.
   If B2 and continuity each pass, the combination gets one further held-out look as its own frozen version.
